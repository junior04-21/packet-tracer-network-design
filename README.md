# Organisational Network Design (Cisco Packet Tracer)

A simulated network for a legal consultancy firm, built as a first-year project at De Montfort University (2024).

## What I built
- A network with routers, switches and end devices
- VLANs, IP addressing and DNS
- Web and file servers
- Device configuration using Cisco IOS CLI
- Fibre optic and copper cable connections between sites

## Tools
Cisco Packet Tracer, Cisco IOS CLI

## How to open
1. Install Cisco Packet Tracer (free from Cisco Networking Academy).
2. Download the `.pkt` file from this repository.
3. Open it in Packet Tracer.
